# Week 1 – Linear algebra with NumPy

Exercises following 3Blue1Brown's *Essence of Linear Algebra*,
implemented in NumPy.

Topics: linear transformations, matrix composition, determinant,
inverse and rank, dot product and projections, change of basis,
eigenvectors, vectorized operations on point clouds.

Includes a small visualization tool that plots how any 2×2 matrix
transforms the unit square.
